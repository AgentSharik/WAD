# WAD — тестовая сборка (прототип)

Один скрипт, который можно «пощупать ручками»: весь путь от заставки до окна после
перезагрузки, но **без единой загрузки и без единого изменения системы**.

## Запуск

Двойной клик по **`WAD-Zapusk.bat`** — или вручную:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -STA -File .\WAD-Prototype.ps1
```

Ключи:

| Ключ | Что делает |
| --- | --- |
| `-SkipIntro` | пропустить титры, сразу к окну установки |
| `-NoRebootSim` | без имитации перезагрузки: только установка и отчёт |

Выход в любой момент — **Esc**.

## Что происходит по шагам

1. **Заставка на весь экран** с титрами: «Здравствуйте» → «Вас приветствует WAD» →
   «WAD настроит Windows для вас, / можете отдохнуть» → «Приступаем».
2. **Окно установки**: 4 категории со статусами (спиннер / ✓ / ❌), нижний бар с
   процентами и плывущим бликом, кнопка «Свернуть в фон» (уходит в трей, значок
   кликабельный), в шапке — «Сайт разработчика».
3. На 100 % бар становится таймером **«Перезагрузка через X сек»**.
4. **Отчёт** реально создаётся в «Документах» и открывается.
5. **Имитация перезагрузки**: чёрный экран «Перезагрузка…» → ваш настоящий рабочий
   стол на 2,5 с → снова наш фуллскрин-фон и титры «Здравствуйте» →
   «Установка системы окончена.» → «Теперь давайте создадим вам пользователя».
6. **Окно создания пользователя**: логин, пароль (пусто = без пароля),
   «Дополнительно» с галочкой «Пользователь создаётся как администратор»
   (включена по умолчанию), кнопка «Создать и продолжить».

## Что реально, а что имитация

| Реально делается | Только показывается |
| --- | --- |
| HTML-отчёт в `Документы\WAD\WAD-отчёт-<дата>.html` | установка программ и компонентов |
| ярлык `WAD — сайт разработчика.lnk` на рабочем столе → GitHub | перезагрузка компьютера |
| окно, таймеры, статусы, отсчёт | создание пользователя (в системе никто не создаётся) |

Ничего не скачивается: в скрипте нет ни одного сетевого вызова — это проверяется
автоматически (см. ниже). Обои берутся из репозитория
(`extras/design/demo/wallpaper-win11.png`), отдельной копией не дублируются; если
файла нет — рисуется градиент.

Отчёт и окно пользователя помечены как тестовая сборка, чтобы интерфейс не выдавал
демонстрационный прогон за настоящую установку.

## Темп

Все тайминги — в блоке `$CFG` в начале `WAD-Prototype.ps1`. По умолчанию они чуть
медленнее ролика, чтобы успеть разглядеть:

```
IntroHold    = 2.8   # титр стоит (в ролике 2.1)
InstallSec   = 30    # имитация установки (в ролике 22)
CountdownSec = 6     # отсчёт до перезагрузки (в ролике 4.5)
DesktopPause = 2.5   # сколько показывать рабочий стол
```

## Проверки

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Проверки-логики.ps1
```

Прогоняет чистую логику без окон (работает и в `pwsh` на любой ОС): прогресс,
состояния категорий, пути, реальная запись отчёта на диск, BOM-кодировка файлов и
запрет на сетевые/системные вызовы (проверяется по дереву разбора, а не поиском
подстрок). Провал — ненулевой код возврата.

## Если что-то не совпадает с роликом

Запусти `WAD-Zapusk.bat -DumpFrames` (или `powershell -File .\WAD-Prototype.ps1 -DumpFrames`).
Прототип без окон отрисует в папку `frames\` одиннадцать PNG — ровно то, что его
GDI+ рисует на этой машине: титры интро, окно установки на разных процентах,
отсчёт и титры после перезагрузки. Пришли эти PNG — по ним расхождение с роликом
видно сразу и правится за один проход, а не вслепую.

Статический анализ: `Invoke-ScriptAnalyzer` — 0 замечаний в категориях Error/Warning
(кроме намеренных: `Write-Host` в консольном прототипе, глаголы `Show-`/`Update-`,
множественные существительные).

## Вёрстка

Все окна рисуются попиксельно (GDI+) на одном холсте — без дочерних контролов с
раскладкой, поэтому DPI и автомасштаб WinForms не могут её сломать. Геометрия окна
1:1 с роликом (1180×720, скругление 10, отступы 56) и автоматически уменьшается,
если экран меньше. Реальные контролы остались только там, где без них нельзя:
поля «Логин» и «Пароль» в окне создания пользователя.

Анимации перенесены из ролика 1:1: чёрный фон перетекает в наш, титры «доезжают»
снизу и уходят вверх с растворением, «Приступаем» — градиентом с растущим
подчёркиванием, окно установки проявляется каскадом строк, бар — с плывущим
бликом.

## Если bat ругается «file does not exist»

Значит, рядом с `WAD-Zapusk.bat` нет `WAD-Prototype.ps1` (скачали только bat, или
файл сохранился как `WAD-Prototype.ps1.txt`). Положите оба файла в одну папку —
bat сам подскажет, чего не хватает.

## Ограничение честности

Логика проверена тестами и анализатором, но **оконный код в песочнице Linux не
запускался** — WinForms там нет. Если на вашем Windows что-то встанет криво,
пришлите скриншот — поправлю по пикселям.
