# Макеты интерфейса WAD

Внутренняя папка: здесь лежит то, что показываем автору до того, как писать код.
Windows в песочнице нет, поэтому интерфейс сначала рисуется картинкой — правки дешёвые,
ошибки видно сразу.

| Файл | Что это |
|---|---|
| `manager-current.html` | Текущее окно менеджера, 1:1 по коду (координаты, шрифты, цвета) + итоговое окно |
| `journey.html` | Весь путь человека: загрузчик → установка по файлу ответов → менеджер → итог |
| `directions.html` | Три направления, которые автор отклонил (оставлены как история решений) |
| `demo/wad-demo.mp4` | Ролик нового интерфейса: 26 с, 1920×1080, фон на весь экран и окно по центру |
| `demo/poster.png` | Кадр из ролика (состояние «идёт установка») |
| `wallpapers/` | Фон ролика и контактный лист этого и трёх других вариантов (в репозитории только используемый — остальные рисуются скриптом) |
| `tools/make_wallpapers.py` | Рисует фоны заново (`python3 extras/design/tools/make_wallpapers.py`) |
| `tools/make_demo.py` | Рисует ролик заново; `--still 8.0` даёт один кадр. Требует `wallpapers/wall-circuit.png` |

Кадры из ролика (`--still`) в репозиторий не кладутся: это воспроизводимая сборка, вес не нужен.

## Про ролик

Собран Python + Pillow + ffmpeg (ставится как `pip install imageio-ffmpeg`) — без браузера
и без Windows. Шрифт в макетах — Inter; **в настоящем окне будет Segoe UI**, он есть в Windows
из коробки, а вшивать шрифт в скрипт смысла нет.

Фон для настоящего интерфейса можно рисовать двумя способами:
1. **кодом** (как `wall-circuit.png`: прямоугольники, линии, узлы) — тогда фона как файла нет
   вовсе, он рисуется GDI+ при запуске и остаётся резким на любом разрешении;
2. **картинкой**, вшитой в скрипт в base64 — тогда вес файла вырастает на размер картинки.
