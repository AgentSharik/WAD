Внутренняя папка: здесь лежит то, что показываем автору до того, как писать код.
Windows в песочнице нет, поэтому интерфейс сначала рисуется картинкой — правки дешёвые,
ошибки видно сразу.

## Про ролик

Собран Python + Pillow + ffmpeg (ставится как `pip install imageio-ffmpeg`) — без браузера
и без Windows. Шрифт в макетах — Inter; **в настоящем окне будет Segoe UI**, он есть в Windows
из коробки, а вшивать шрифт в скрипт смысла нет.

Фон для настоящего интерфейса можно рисовать двумя способами:
1. **кодом** (как `wall-circuit.png`: прямоугольники, линии, узлы) — тогда фона как файла нет
   вовсе, он рисуется GDI+ при запуске и остаётся резким на любом разрешении;
2. **картинкой**, вшитой в скрипт в base64 — тогда вес файла вырастает на размер картинки.


## Про предпросмотр (`prototype/manager-preview.ps1`)

Это не картинка и не макет: настоящий код WinForms, который рисует будущий интерфейс на вашем
экране. Запуск (права администратора не нужны):

```
powershell -ExecutionPolicy Bypass -File manager-preview.ps1
powershell -ExecutionPolicy Bypass -File manager-preview.ps1 -Seconds 12   # покороче
powershell -ExecutionPolicy Bypass -File manager-preview.ps1 -Windowed     # окно вместо всего экрана
```

Выход — клавиша Esc или крестик в правом верхнем углу.

Что уже проверено здесь, без Windows:
- код разбирается и совместим с **Windows PowerShell 5.1** (на домашних ПК стоит именно он);
- логика состояний и процентов прогнана по точкам времени: `waiting → run → ok/warn`, финал 100 %;
- фон и «стекло» считаются кодом: настоящего размытия в GDI+ нет, но приём «уменьшить и растянуть»
  отличается от него на 0.6 из 255 — глазом не видно (`demo/glass-test.png`).

Чего проверить здесь **нельзя** — только вашими глазами на Windows: как выглядит на самом деле,
плавность анимации, поведение при масштабе экрана 125–150 %. Прогресс в предпросмотре
имитируется: реальные задачи не запускаются.


## Про ролик прототипа

`demo/prototype-demo.mp4` — не «похожая картинка», а тот же код: те же координаты, тот же алгоритм
фона, тот же приём со «стеклом» (уменьшить и растянуть), что и в `prototype/manager-preview.ps1`.
Даже узор на фоне совпадёт: он строится генератором случайных чисел .NET, который здесь повторён
и **сверен с PowerShell** — 60 чисел подряд совпадают.

Отличия от окна на Windows три, и все мелкие:
1. шрифт — здесь Inter, в Windows будет Segoe UI (метрики близкие, но не совпадают до пикселя);
2. в ролике есть затемнение в начале и конце — это монтаж, в самом окне его нет;
3. сглаживание линий и текста делают разные движки (GDI+ против Pillow) — в мелочах видно.

Проверка фона без запуска окна: `demo/prototype-background.png` — его нарисовал тот же генератор.

**Ролики в репозиторий не попадают:** в `.gitignore` есть правило `*.mp4` (заводилось под записи
прогонов в виртуальной машине). Файлы лежат в рабочей папке и пересобираются командами выше;
в репозитории остаются обложки, фон и скрипты сборки. Нужно положить ролик в репозиторий —
правится одной строкой `.gitignore`.


## Полный путь в стиле Windows 11 (`tools/make_wad_flow.py`)

Это выбранное направление. Ролик показывает всё, что увидит человек, одним куском — 55 секунд:

| Время | Что на экране |
|---|---|
| 0–12 с | только фон и приветствие: «Здравствуйте» → «Вас приветствует WAD» → «WAD настроит Windows для вас, можете отдохнуть» |
| 10–12,4 с | «Приступаем», и в это же время окно начинает проступать прямо из фона |
| 12,4–23 с | начальное окно (10 секунд в покое): что установим, что настроим, 3 факта, две кнопки |
| 23–47,6 с | установка: крупные кружки шагов и анимированная линия между ними, чипы «Что делает эта задача», честные замечания по двум программам |
| 44,9–47,6 с | финал установки: «Все задачи выполнены», 100 %, кнопка меняется на «Перезагрузить компьютер» |
| 47,6–53,4 с | окно проекта на GitHub: настоящие цифры, темы, история изменений, QR-код |
| 53,4–55 с | окно растворяется обратно в фон — так же, как и появлялось |

Собирается так:
```
python3 extras/design/tools/make_wad_flow.py            # весь ролик
python3 extras/design/tools/make_wad_flow.py --still 30 # один кадр на 30-й секунде
```

Скрипт сам скачивает шрифт (Inter в `~/.cache/fonts`) и при необходимости доставляет `segno`
для QR-кода, так что на чистой машине достаточно Python, Pillow и интернета.

Что здесь честно: шрифт в макете Inter, в настоящем окне будет Segoe UI (в Windows он есть
из коробки); цифры про репозиторий взяты из API 11 сентября 2026 и в окне подписаны датой;
ролик собран картинками, а не запуском программы — настоящего окна в песочнице нет.


## Три дизайна (`tools/make_designs.py`)

Каждое видео показывает **полный путь** в одном стиле: стартовое окно (4,5 с) → установка (22 с) →
окно проекта на GitHub (5,5 с).

| Дизайн | Как выглядит | Прогресс |
|---|---|---|
| **Кольцо** | тёмный, синий с фиолетовым, стеклянная подложка | кольцо и крупное число по центру |
| **Светлый** | светлая тема, плотная белая карточка с тенью | шаги слева направо, проценты в шапке |
| **Терминал** | почти чёрный, зелёный моно, рамка консоли | сегментная полоса, живой журнал справа |

Пересобрать всё:
```
python3 extras/design/tools/make_designs.py --design ring --video
python3 extras/design/tools/make_designs.py --design day  --video
python3 extras/design/tools/make_designs.py --design console --video
python3 extras/design/tools/make_designs.py --design console --scene github --still 4   # один кадр
```

### Про окно GitHub

Данные в нём **настоящие**, взятые из API 11 сентября 2026: `AgentSharik/WAD`, 0 звёзд, 0 форков,
671 КБ, PowerShell, лицензия не выбрана, 8 тем, обновлён 10.09.2026. Если цифры устареют — они
правятся в одном месте (словарь `REPO` в начале `make_designs.py`), а не разбросаны по коду.

QR-код не картинка: он строится библиотекой `segno` из настоящей ссылки на репозиторий,
поэтому ведёт куда заявлено.

В настоящей программе эти данные можно брать из API при каждом запуске — публичный репозиторий
отдаёт их без пароля и токена. Ограничение: без интернета окно покажет последние сохранённые
цифры, а не свежие, и это придётся писать честно («данные на такое-то число»).

### Напоминание про вес

Репозиторий держим лёгким: ролики (`design-*.mp4`, `prototype-demo.mp4`, `wad-demo.mp4`) исключены
правилом `*.mp4` в `.gitignore` и лежат только в рабочей папке. В репозиторий идут обложки,
обзорная таблица и скрипты сборки — этого достаточно, чтобы всё пересобрать.
