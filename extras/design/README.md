# Макеты интерфейса WAD

Внутренняя папка: здесь лежит то, что показываем автору до того, как писать код.
Windows в песочнице нет, поэтому интерфейс сначала рисуется картинкой — правки дешёвые,
ошибки видно сразу.

## Про ролик

Собран Python + Pillow + ffmpeg (ставится как `pip install imageio-ffmpeg`) — без браузера
и без Windows. Шрифт в макетах — **Source Sans 3** (свободная, с полной кириллицей, по пропорциям
ближе всего к Segoe UI из доступного; почему не Segoe UI и не Selawik — ниже). В настоящем окне
будет системный **Segoe UI**, он есть в Windows из коробки, а вшивать шрифт в скрипт смысла нет.

Фон для настоящего интерфейса можно рисовать двумя способами:
1. **кодом** (как `wall-circuit.png`: прямоугольники, линии, узлы) — тогда фона как файла нет
   вовсе, он рисуется GDI+ при запуске и остаётся резким на любом разрешении;
2. **картинкой**, вшитой в скрипт в base64 — тогда вес файла вырастает на размер картинки.


## Про предпросмотр (`prototype/manager-preview.ps1`)

Это не картинка и не макет: настоящий код WinForms, который рисует будущий интерфейс на вашем
экране. Запуск (права администратора не нужны):

```
powershell -ExecutionPolicy Bypass -File manager-preview.ps1
powershell -ExecutionPolicy Bypass -File manager-preview.ps1 -Seconds 12   # покороче
powershell -ExecutionPolicy Bypass -File manager-preview.ps1 -Windowed     # окно вместо всего экрана
```

Выход — клавиша Esc или крестик в правом верхнем углу.

Что уже проверено здесь, без Windows:
- код разбирается и совместим с **Windows PowerShell 5.1** (на домашних ПК стоит именно он);
- логика состояний и процентов прогнана по точкам времени: `waiting → run → ok/warn`, финал 100 %;
- фон и «стекло» считаются кодом: настоящего размытия в GDI+ нет, но приём «уменьшить и растянуть»
  отличается от него на 0.6 из 255 — глазом не видно (`demo/glass-test.png`).

Чего проверить здесь **нельзя** — только вашими глазами на Windows: как выглядит на самом деле,
плавность анимации, поведение при масштабе экрана 125–150 %. Прогресс в предпросмотре
имитируется: реальные задачи не запускаются.


## Про ролик прототипа (`tools/make_prototype_video.py`)

Ролик показывает не «похожую картинку», а тот же код: те же координаты, тот же алгоритм
фона, тот же приём со «стеклом» (уменьшить и растянуть), что и в `prototype/manager-preview.ps1`.
Даже узор на фоне совпадёт: он строится генератором случайных чисел .NET, который в скрипте повторён
и **сверен с PowerShell** — 60 чисел подряд совпадают.

Отличия от окна на Windows три, и все мелкие:
1. шрифт — в макете Source Sans 3, в Windows будет Segoe UI (метрики близкие, но не совпадают до пикселя);
2. в ролике есть затемнение в начале и конце — это монтаж, в самом окне его нет;
3. сглаживание линий и текста делают разные движки (GDI+ против Pillow) — в мелочах видно.

Проверка фона без запуска окна: `demo/prototype-background.png` — его нарисовал тот же генератор.

**Ролики в репозиторий не попадают:** в `.gitignore` есть правило `*.mp4` (заводилось под записи
прогонов в виртуальной машине). В рабочей папке держим **один актуальный ролик** —
`demo/wad-full.mp4`; остальные не копим, чтобы не разрасталась папка: они собираются из скриптов
одной командой, кадр в кадр из того же кода.

| Что нужно | Команда |
|---|---|
| Актуальный ролик (весь путь) | `python3 extras/design/tools/make_wad_flow.py` |
| Дизайн «Кольцо» / «Светлый» / «Терминал» | `python3 extras/design/tools/make_designs.py --design ring --video` (и так же `day`, `console`) |
| Ролик прототипа (по коду WinForms) | `python3 extras/design/tools/make_prototype_video.py` |
| Первый ролик-макет | `python3 extras/design/tools/make_demo.py` |

Нужно положить ролик в репозиторий — правится одной строкой `.gitignore`.


## Полный путь в стиле Windows 11 (`tools/make_wad_flow.py`)

| Время | Что на экране |
|---|---|
| 0–1,3 с | чёрный экран, белым проявляется «Здравствуйте» |
| 1,3–3,75 с | «Здравствуйте» стоит на чёрном и гаснет, пока фон ещё чёрный |
| 3,75–4,6 с | чёрный уходит в основной фон **уже пустым** — на светлых обоях этого слова нет |
| 4,15–8,25 с | «Вас приветствует WAD» на светлых обоях, «WAD» — синий с фиолетовым |
| 8,5–12,6 с | «WAD настроит Windows для вас, / можете отдохнуть» — двумя строками |
| 12,85–16,95 с | «Приступаем» с подчёркиванием |
| 16,95–17,7 с | на экране только фон: приветствие закончилось, окна ещё нет |
| 17,7–19,3 с | окно **проступает из обоев за 1,6 с** — сразу вместе с содержимым |
| 19,3–25,3 с | начальное окно стоит ровно 6 с: что установим, что настроим, четыре факта и одна кнопка |
| 25,3–47,3 с | установка: крупные кружки шагов и анимированная линия между ними, чипы «Что делает эта задача», честные замечания по двум программам из шести |
| 47,3–48,9 с | финал установки: «Все задачи выполнены», 100 %, «Свернуть в фон» |
| 47,9–48,9 с | окно проекта на GitHub перетекает на место: старое растворяется, новое подтягивается снизу-справа |
| 48,9–52,8 с | окно проекта: настоящие цифры, темы репозитория, QR-код и **одна кнопка — «Перезагрузить компьютер»** |

Каждая строка приветствия живёт по одному сценарию: 0,9 с проявляется снизу (на 34 px), 2,1 с стоит,

исчезла, поэтому нет ни наложения текстов, ни пустых провалов: от ухода «Здравствуйте» до появления
второй строки проходит 0,4 с, а не две секунды, как было раньше.

Собирается так:
```
python3 extras/design/tools/make_wad_flow.py            # весь ролик
python3 extras/design/tools/make_wad_flow.py --still 30 # один кадр на 30-й секунде
```

Скрипт сам скачивает шрифт (Source Sans 3 в `~/.cache/fonts`) и при необходимости доставляет `segno`
для QR-кода, так что на чистой машине достаточно Python, Pillow и интернета.

Чего в ролике намеренно нет:

- **системной полосы заголовка Windows** — знак WAD, название раздела и значки управления
  нарисованы внутри окна, поэтому оно выглядит цельным, а не карточкой с приклеенной полоской;
- **кнопки «Начать установку»** в начальном окне — установка начинается сама, человеку нечего нажимать;
- **кнопки перезагрузки в окне установки** — перезагрузка переехала в окно проекта на GitHub:
  сначала человек видит результат, потом действие;
- **кнопок «Проверить обновления» и «Открыть в браузере»** в окне проекта: данные и так свежие,
  взятые с GitHub при открытии окна, а браузер на перезагружаемой машине не нужен. Осталась одна
  кнопка — «Перезагрузить компьютер»;
- **истории изменений** в окне проекта: подписи вида «0.2 / 0.3 / 0.4» читались как нумерация
  версий самой программы, которой пока нет, а последняя строка налезала на подпись внизу окна.

Белая обводка вокруг «WAD» и «Приступаем» заменена мягким свечением: обводка давала жёсткий контур
вокруг каждой буквы («белые углы»), свечение размыто на 7 px и выделяет слова, не рисуя контура.

Что здесь честно:

- **шрифт.** Настоящий Segoe UI взять нельзя: он лицензионный и в песочнице его нет. Selawik —
  единственный свободный шрифт, совместимый с Segoe UI по метрикам, — проверили: **кириллицы в нём
  нет** (0 русских глифов из 348). Поэтому в макете **Source Sans 3**: свободная, полная кириллица,
  по пропорциям ближе всего к Segoe UI из доступного. Сравнение четырёх вариантов — `demo/font-compare.png`.
  Смена семейства в скрипте — одна строка (`FONT_FAMILY` в начале файла: `sourcesans3` | `fira` | `inter`);
- цифры про репозиторий взяты из API 11 сентября 2026 и в окне подписаны датой;
- ролик собран картинками, а не запуском программы — настоящего окна в песочнице нет.


## Три дизайна (`tools/make_designs.py`)

Каждое видео показывает **полный путь** в одном стиле: стартовое окно (4,5 с) → установка (22 с) →
окно проекта на GitHub (5,5 с).

| Дизайн | Как выглядит | Прогресс |
|---|---|---|
| **Кольцо** | тёмный, синий с фиолетовым, стеклянная подложка | кольцо и крупное число по центру |
| **Светлый** | светлая тема, плотная белая карточка с тенью | шаги слева направо, проценты в шапке |
| **Терминал** | почти чёрный, зелёный моно, рамка консоли | сегментная полоса, живой журнал справа |

Пересобрать всё:
```
python3 extras/design/tools/make_designs.py --design ring --video
python3 extras/design/tools/make_designs.py --design day  --video
python3 extras/design/tools/make_designs.py --design console --video
python3 extras/design/tools/make_designs.py --design console --scene github --still 4   # один кадр
```

### Про окно GitHub

Данные в нём **настоящие**, взятые из API 11 сентября 2026: `AgentSharik/WAD`, 671 КБ, PowerShell,
лицензия не выбрана, 8 тем, обновлён 10.09.2026. Звёзд и форков в окне нет намеренно — их пока ноль.
Если цифры устареют — они
правятся в одном месте (словарь `REPO` в начале `make_wad_flow.py`), а не разбросаны по коду.

QR-код не картинка: он строится библиотекой `segno` из настоящей ссылки на репозиторий,
поэтому ведёт куда заявлено.

В настоящей программе эти данные можно брать из API при каждом запуске — публичный репозиторий
отдаёт их без пароля и токена. Ограничение: без интернета окно покажет последние сохранённые
цифры, а не свежие, и это придётся писать честно («данные на такое-то число»).

### Напоминание про вес

Репозиторий держим лёгким: ролики исключены правилом `*.mp4` в `.gitignore` и в рабочей папке
лежит только один — `demo/wad-full.mp4`. В репозиторий идут обложки, обзорная таблица, фоны
и скрипты сборки — этого достаточно, чтобы пересобрать любой ролик одной командой.
